# Aniboo

Aplicação web para busca e descoberta de animes, desenvolvida inicialmente com JavaScript, HTML e CSS, utilizando a Jikan API.

Atualmente, o projeto está em reformulação, com uma migração para React e melhorias na estrutura e interface da aplicação.

### Tecnologias
- JavaScript
- React (em desenvolvimento)
- HTML5
- CSS3
- Jikan API
- LocalStorage

### Status
🚧 Em reformulação.

### Objetivo
Aprimorar meus conhecimentos em desenvolvimento Front-end, consumo de APIs e React por meio da evolução de um projeto já existente.
