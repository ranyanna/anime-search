Olá! Sou Ranyanna Ayala, estudante de Engenharia de Software na Unigran Capital, e o AniBoo é um dos projetos que desenvolvi para construir meu portfólio como desenvolvedora Front-End. O projeto consome a API pública Jikan (MyAnimeList) e permite buscar animes por nome, visualizar informações como gênero e pontuação, e salvar seus favoritos, que ficam guardados mesmo após fechar o navegador, graças ao localStorage. Desenvolvido com HTML, CSS e JavaScript puro, sem frameworks, com foco em boas práticas, clean code e experiência do usuário.
